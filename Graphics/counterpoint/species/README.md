# Gradus ad Parnassum Species Counterpoint Exercises

This directory contains Johann Joseph Fux's complete species counterpoint exercises from "Gradus ad Parnassum" (1725).

## Source

**Repository:** [MarkGotham/species](https://github.com/MarkGotham/species)

## Contents

### Part I: Two-Voice Counterpoint (46 exercises)
- `I-Exercises` - Cantus firmus only
- `I-Solutions` - Fux's complete solutions
- `I-Annotations` - Solutions with interval markings
- `I-Distinct` - Unique cantus firmus patterns

### Part II: Three-Voice Counterpoint (44 exercises)
- Same file structure as Part I

### Part III: Four-Voice Counterpoint (32 exercises)
- Same file structure as Part I

## File Formats

Each file is available in three formats:
- `.mscz` - MuseScore format (editable)
- `.mxl` - MusicXML format (universal, works with any notation software)
- `.pdf` - PDF format (for viewing/printing)

## Usage

Open `.mscz` files in [MuseScore](https://musescore.org/) (free) or import `.mxl` files into any music notation software (Sibelius, Finale, Dorico, etc.).

## Reference

Figure numbers follow the Norton/Mann edition (1965).
