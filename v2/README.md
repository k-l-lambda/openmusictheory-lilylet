# Open Music Theory (2nd edition)

Markdown conversion of [*Open Music Theory*, Version 2](https://viva.pressbooks.pub/openmusictheory/), Mark Gotham, Kyle Gullings, Chelsey Hamm, Bryn Hughes, Brian Jarvis, Megan Lavengood, John Peterson; edited by Erin K. Maher. Licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); each chapter lists its own authors.

Converted by `scripts/v2/convert.py` from the Pressbooks REST API and the book's WXR export. Images, score files and audio are in `media/`; worksheets (docx/pdf) and videos link to Pressbooks. MuseScore embeds, videos and interactive exercises are links. See [MATERIALS.md](MATERIALS.md) for an inventory of the score materials.
