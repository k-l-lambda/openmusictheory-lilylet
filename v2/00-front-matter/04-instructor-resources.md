# Instructor Resources

We have set up a community for instructors on Knowledge Commons (formerly known as Humanities Commons) so that anyone using *OMT*can share material with other instructors. The community also has a discussion board.

The instructor community provides many resources:

- Course calendars and syllabi for core theory classes and electives
- Answer keys for worksheets
- Additional assignments and projects
- Sample exams
- Discussion board
