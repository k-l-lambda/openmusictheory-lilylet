This section introduces some common methodologies for the analysis of 20th- and 21st-century music, including set theory.

## Prerequisites

This section assumes a familiarity with the topics covered in [Fundamentals](../01-fundamentals/README.md).

## Organization

The first chapter introduces several [approaches to rhythm](01-twentieth-century-rhythmic-techniques.md) used by composers of twentieth-century Western concert music.

The next five chapters introduce students to the building blocks of set theory: integer notation, [pitches vs. pitch classes](02-pitch-and-pitch-class.md), [intervals and interval classes](03-intervals-in-integer-notation.md), [sets](04-pc-sets-normal-order-and-transformations.md) and [set classes](05-set-class-and-prime-form.md), [operations](04-pc-sets-normal-order-and-transformations.md), and [interval class vectors](06-interval-class-vectors.md).

The chapter [Analyzing with Set Theory (or not!)](07-analyzing-with-set-theory.md) is an important conclusion to these earlier chapters: it discusses the philosophy of segmentation and also turns a critical eye to set theory as a methodology. What makes us group notes together and call them sets? What are we ignoring when we use set theory?

The final three chapters discuss [collections](09-collections.md), including modes, the octatonic collection, and others. Students are also taught here how tonic pitches can be heard within a composition using these collections, and how to [analyze pieces with collections](10-analyzing-with-collections-scales-and-modes.md).
