# Embellishing Tones

## Summary

Embellishing tones (non-chord tones) add melodic interest by creating and resolving tension against the underlying harmony. Each type has specific approach, departure, and metric characteristics.

## Passing Tone (PT)

**Definition:** Melodic embellishment connecting two chord tones by step.

| Feature | Value |
|---------|-------|
| Approach | Step |
| Departure | Step (same direction) |
| Pattern | Chord tone → PT → Chord tone |
| Interval filled | Third (or fourth with two PTs) |
| Metric | Accented or unaccented |

**Example:**
```
C - D - E  (D is PT filling in C-E third)
```

**Score example:** [PT over a sustained tonic: E5–**D5**–C5 above C3](../examples/07-melodic-elaboration/passing-tone.md)

## Complete Neighbor Tone (NT)

**Definition:** Embellishment departing from and returning to the same chord tone.

| Feature | Value |
|---------|-------|
| Approach | Step |
| Departure | Step (opposite direction) |
| Pattern | CT → NT → same CT |
| Types | Upper neighbor, lower neighbor |
| Metric | Usually unaccented |

**Example:**
```
E - F - E  (F is upper neighbor)
E - D - E  (D is lower neighbor)
```

**Score example:** [upper NT: E5–**F5**–E5 above C3](../examples/07-melodic-elaboration/neighbor-tone.md)

## Double Neighbor Figure (DN)

**Definition:** Two embellishing tones, one above and one below, surrounding a chord tone.

| Feature | Value |
|---------|-------|
| Pattern | CT → step above → step below → CT (or reverse) |
| Balance | Upper and lower neighbors balance out |
| Metric | Typically unaccented |
| Effect | Contiguous, stable overall |

**Example:**
```
E - F - D - E  (F=upper, D=lower, returns to E)
```

**Score example:** [DN: E5–**F5 D5**–E5 above C3](../examples/07-melodic-elaboration/double-neighbor.md)

## Incomplete Neighbor Tone (INT)

**Definition:** Neighbor tone connected by leap on one side.

| Feature | Value |
|---------|-------|
| Approach | Leap |
| Departure | Step |
| Metric | Unaccented |
| Destination | Accented chord tone |

**Score example:** [INT: G5 leaps to **D5**, steps up to accented E5](../examples/07-melodic-elaboration/incomplete-neighbor.md)

## Appoggiatura (APP)

**Definition:** Accented incomplete neighbor approached by leap.

| Feature | Value |
|---------|-------|
| Approach | Leap (usually up) |
| Departure | Step (usually down) |
| Metric | **Accented** |
| Character | Expressive, "leaning" |

**Key distinction:** Appoggiatura is accented (on the beat), unlike other incomplete neighbors.

**Score example:** [two accented APPs, **D5**→C5 and **F5**→E5, over the bass arrival on C3](../examples/07-melodic-elaboration/appoggiatura.md)

## Escape Tone (ESC)

**Definition:** Unaccented embellishment approached by step, left by leap.

| Feature | Value |
|---------|-------|
| Approach | Step (usually up) |
| Departure | Leap (usually down) |
| Metric | Unaccented |
| French name | Échappée |

**Pattern:** Opposite of appoggiatura — step→leap instead of leap→step.

**Score example:** [two ESCs: E5–**F5**→D5 and D5–**E5**→C5 (step up, leap down)](../examples/07-melodic-elaboration/escape-tone.md)

## Anticipation (ANT)

**Definition:** A chord tone that arrives early, before its chord.

| Feature | Value |
|---------|-------|
| Approach | Step |
| Departure | Same note (held or rearticulated) |
| Metric | Unaccented, before change of harmony |
| Location | Phrase endings, cadences |

**Example:**
```
V  →  I
...G → G  (G anticipates tonic before chord change)
```

**Score example:** [cadential ANT: B4–**C5** over V, C5 rearticulated on I](../examples/07-melodic-elaboration/anticipation.md)

## Syncopation (SYN)

**Definition:** Rhythmic displacement where a tone arrives early and ties into the following beat.

| Feature | Value |
|---------|-------|
| Mechanism | Tied note across beat/barline |
| Effect | Early arrival, held |
| vs. Anticipation | Tied (not rearticulated) |

**Score example:** [tied early arrivals in a sung melody (B4 tied over the barline into Bsus4)](../examples/07-melodic-elaboration/syncopation.md)

## Suspension (SUS)

**Definition:** A three-part figure where a chord tone is held over a harmony change, creating dissonance before resolving down.

### Three Parts

| Part | Description | Metric |
|------|-------------|--------|
| Preparation | Chord tone, consonant | Either |
| Suspension | Same note, now dissonant | **Accented** |
| Resolution | Step down to chord tone | Unaccented |

### Common Suspension Types

| Notation | Intervals |
|----------|-----------|
| 9-8 | 9th resolves to octave |
| 7-6 | 7th resolves to 6th |
| 4-3 | 4th resolves to 3rd |

**Guideline:** For best voice-leading, avoid having resolution pitch class sound in another voice simultaneously (except 9-8).

**Score example:** [4–3 over V: C5 prepared over IV, restruck over G3, resolves to B4](../examples/07-melodic-elaboration/suspension.md)

## Retardation (RET)

**Definition:** Upward-resolving suspension.

| Feature | Value |
|---------|-------|
| Preparation | Chord tone |
| Retardation | Held, accented |
| Resolution | Step **up** |
| Location | Final chords of large sections |

Often appears with a regular suspension (e.g., 7-8 retardation + 4-3 suspension simultaneously).

**Score example:** [final chord: B4→C5 retardation (7–8) with F4→E4 suspension (4–3)](../examples/07-melodic-elaboration/retardation.md)

## Comparison Table

| Type | Approach | Departure | Metric | Direction |
|------|----------|-----------|--------|-----------|
| PT | Step | Step | Either | Same |
| NT | Step | Step | Unacc. | Opposite |
| DN | Step | Step | Unacc. | Both |
| INT | Leap | Step | Unacc. | — |
| APP | Leap | Step | **Acc.** | Down |
| ESC | Step | Leap | Unacc. | Down |
| ANT | Step | Same | Unacc. | — |
| SUS | Held | Step | **Acc.** | Down |
| RET | Held | Step | **Acc.** | Up |
| SYN | Tied | Tied | Weak→Strong | — |

## Compositional Application

### Choosing Embellishments

| Goal | Use |
|------|-----|
| Fill melodic gaps | PT |
| Decorate stable tone | NT, DN |
| Create expressive accent | APP, SUS |
| Smooth phrase endings | ANT |
| Add rhythmic interest | SYN |
| Final chord weight | RET + SUS |

### Voice-Leading Integration

- NCTs must resolve properly to chord tones
- Avoid parallel 5ths/8ves created by NCT motion
- Accented NCTs need careful preparation
