# Large Forms

## Summary

Large forms are multi-section structures that organize extended musical movements. They range from simple two-part forms to complex sonata structures with multiple thematic areas and tonal journeys.

## Form Categories

| Form | Sections | Key Scheme | Typical Use |
|------|----------|------------|-------------|
| Small Binary | A + B | I→V + V→I | Minuet themes, variations |
| Small Ternary | A + B + A' | I→(V) + CM + I | Dance movements |
| Sonata | Exp + Dev + Recap | I→V + unstable + I | First movements |
| Rondo | A-B-A-C-A | I + contrast + I | Finales |

## Structural Principles

### Tonal Journey

All large forms involve departure from and return to tonic:

```
HOME KEY → AWAY → HOME KEY
```

### Thematic Return

Most forms include recapitulation of opening material:
- **Small ternary**: A returns after B
- **Sonata**: Exposition returns as recapitulation
- **Rondo**: Refrain alternates with episodes

### Cadential Goals

Each section has structural cadential goals:
- **Expositions**: End away from tonic (V:PAC or III:PAC)
- **Development/Middle**: End on dominant (I:HC)
- **Recapitulations**: End in tonic (I:PAC)

## Form Comparison

| Feature | Binary | Ternary | Sonata | Rondo |
|---------|--------|---------|--------|-------|
| Sections | 2 | 3 | 3 | 5-7 |
| Recap? | No | Yes | Yes | Yes (refrain) |
| Development? | Minimal | CM | Extensive | Episodes |
| Key contrast | Moderate | Moderate | Strong | Varied |
