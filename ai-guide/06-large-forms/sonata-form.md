# Sonata Form

## Summary

Sonata form is the most important large-scale form in classical music, characterized by a two-part exposition with contrasting key areas, an unstable development, and a recapitulation that resolves the tonal tension.

## Overall Structure

```
INTRODUCTION (optional) → EXPOSITION → DEVELOPMENT → RECAPITULATION → CODA (optional)
```

| Section | Tonal Goal | Thematic Content |
|---------|-----------|------------------|
| Exposition | Establish contrast (I→V) | P-TR-S-C cycle |
| Development | Instability | Fragmentation, sequence |
| Recapitulation | Resolution (I) | P-TR-S-C in tonic |

## The Exposition

The exposition presents the main themes and establishes tonal contrast.

### Two-Part Exposition Structure

```
Part 1: P → TR → MC (half cadence)
Part 2: S → EEC → C
```

### Thematic Modules

#### Primary Theme (P)

| Function | Description |
|----------|-------------|
| Establish home key | Begins and cadences in tonic |
| Present primary material | Main melodic idea |
| Begin thematic cycle | First theme of rotation |

- Usually tight-knit (sentence or period)
- Ends with I:PAC or I:HC
- May have P1 + P2 (primary theme group)

#### Transition (TR)

| Function | Description |
|----------|-------------|
| Drive toward MC | Energy gain |
| Modulate (optional) | Move to secondary key |
| Prepare S | Create expectation |

**TR Types:**
- **Non-modulating**: Leads to I:HC MC
- **Modulating**: Leads to V:HC MC (major) or III:HC MC (minor)

**Melodic Types:**
- **Independent TR**: New thematic material
- **Dissolving TR**: Begins like P, then degenerates

**Characteristics**: Continuation function—fragmentation, liquidation, acceleration

#### Subordinate Theme (S)

| Function | Description |
|----------|-------------|
| Contrast | New key, often new character |
| Drive to EEC | Goal-oriented |
| Dramatize closure | Delay and emphasize PAC |

- In secondary key (V in major, III in minor)
- Looser than P—extended continuations, expanded cadential passages
- May share material with P (mono-thematic sonata)
- Leads to Essential Expositional Closure (EEC)

#### Closing Module (C)

| Function | Description |
|----------|-------------|
| Post-cadential | Follows EEC |
| Confirm secondary key | Reinforce arrival |
| Prepare repeat | Lead back to P or forward |

- New material, or borrowed from P/TR
- Cannot be S-based (that would continue S)
- Always in secondary key

### Structural Points of Arrival

#### Medial Caesura (MC)

**Definition**: Rhetorical break marking end of Part 1, preparing S.

**Characteristics**:
- Associated with half cadence (not the same as HC)
- Often preceded by "dominant lock" (standing on V)
- Often marked by rests, "hammer blows"
- Types: I:HC MC, V:HC MC, III:HC MC

**Common approach**: fa-fi-sol bass line into HC

#### Essential Expositional Closure (EEC)

**Definition**: First satisfactory PAC in secondary key followed by differing material.

**Requirements**:
1. Must be a PAC in secondary key
2. Must be followed by NEW material (C)
3. First such PAC (not necessarily strongest)

## The Development

The development is the least conventional section, characterized by instability.

### Tonal Organization

- Explores subordinate keys (vi, iii, ii in major; iv, v in minor)
- Keys often confirmed by HC, not PAC
- Returns to tonic via dominant preparation

### Thematic Organization

- Any exposition material may appear
- P and TR material most common
- May introduce new material
- Not bound to exposition order

### Four Modules

| Module | Function |
|--------|----------|
| 1. Link (optional) | Bridge from exposition |
| 2. Entry zone | Preparatory, often piano, P-based |
| 3. Central action zone (CAZ) | Core instability: sequence, fragmentation |
| 4. Retransition | Standing on dominant, prepares recap |

### Central Action Zone

- Establishes 2-, 4-, or 8-bar model
- Sequences (especially D2, A2)
- Fragmentation intensifies
- Concludes with I:HC

### Retransition

- Follows development HC
- Standing on dominant
- May foreshadow P material
- Builds anticipation for recapitulation

## The Recapitulation

The recapitulation resolves the tonal tension of the exposition.

### Structure

```
P → TR → MC → S → ESC → C
```

All in tonic key.

### Essential Sonata Closure (ESC)

**Definition**: The recapitulation's counterpart to the EEC.

- Always I:PAC
- Occurs at same thematic point as EEC
- Often same music as EEC, transposed to tonic

### Recomposition

Because the exposition modulated, the recapitulation often requires changes:

| Material Type | Description |
|---------------|-------------|
| Correspondence bars | Same as exposition (or transposed) |
| Referential bars | Clear reference but altered |
| Alterations | No clear correspondence |

**Typical pattern**:
```
Correspondence (P, early TR) → Alterations (late TR) → Correspondence (S, C transposed)
```

### Crux

The point where alterations give way to renewed correspondence (usually before S).

## Key Relationships

### Major Mode

| Section | Key |
|---------|-----|
| Exposition P | I |
| Exposition S/C | V |
| Development | Various (vi, ii, etc.) |
| Recapitulation | I throughout |

### Minor Mode

| Section | Key |
|---------|-----|
| Exposition P | i |
| Exposition S/C | III (relative major) |
| Development | Various (iv, v, etc.) |
| Recapitulation | i throughout |

## Sonata Form Template

### Two-Part Exposition (Major)

```
Bars 1-8:    P (sentence) → I:PAC
Bars 9-16:   TR (dissolving) → V:HC MC
Bars 17-24:  S (loose) → V:PAC (EEC)
Bars 25-32:  C → V:PAC
```

### Development

```
Bars 33-36:  Entry zone (P-based)
Bars 37-48:  CAZ (sequence, fragmentation)
Bars 49-56:  Retransition → I:HC
```

### Recapitulation

```
Bars 57-64:  P (correspondence)
Bars 65-72:  TR (altered for tonic)
Bars 73-80:  S (transposed to I) → I:PAC (ESC)
Bars 81-88:  C (transposed to I)
```

## Compositional Application

### Analysis Checklist

1. Locate MC (look for break before S)
2. Identify EEC (first PAC in V/III followed by new material)
3. Map thematic modules (P-TR-S-C)
4. Identify correspondence/alterations in recap
5. Locate ESC

### Common Mistakes

| Mistake | Correction |
|---------|------------|
| EEC is strongest PAC | EEC is FIRST satisfactory PAC |
| MC = cadence | MC follows cadence, is rhetorical break |
| S must contrast | S may be P-based (mono-thematic) |

## Constraints

1. **MC**: Must be followed by satisfactory S theme
2. **EEC**: Must be in secondary key, followed by differing material
3. **ESC**: Must be I:PAC
4. **Recapitulation**: S and C must be in tonic
