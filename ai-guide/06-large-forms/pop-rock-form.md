# Pop/Rock Form

## Summary

Pop/rock songs typically follow one of three large-scale formal patterns: strophic form (AAA), 32-bar song form (AABA), or verse-chorus form (VC/VCB). Each has distinct module types and cycle structures.

## The Three Main Forms

| Form | Structure | Era | Primary Module |
|------|-----------|-----|----------------|
| Strophic | AAA | 1950s-60s | Strophe |
| AABA | {AABA}{BA} | 1950s-60s | Strophe |
| Verse-Chorus | {VPC}{VPC}{BC} | 1960s-present | Chorus |

## Strophic Form (AAA)

### Definition

The same basic multi-phrase unit (strophe) repeats throughout, with lyrics changing but music remaining essentially the same.

### Structure

```
Strophe 1 → Strophe 2 → [Instrumental] → Strophe 3 → ...
```

### Characteristics

- Single core module type (strophe)
- May include auxiliary modules (intro, outro, coda)
- Instrumental sections use strophe harmony

### Example: Carl Perkins — "Blue Suede Shoes"

```
0:00  Strophe 1
0:19  Strophe 2
0:41  Instrumental strophe
0:58  Strophe 3
1:21  Instrumental strophe
1:37  Strophe 1 (varied)
1:54  Strophe 4
```

## 32-Bar Song Form (AABA)

### Definition

Two strophes followed by a contrasting bridge, then return to strophe. Named for early Tin Pan Alley songs with 8-bar sections.

### Module Types

| Module | Function | Contains |
|--------|----------|----------|
| A (Strophe) | Primary | Main melody, title lyrics |
| B (Bridge) | Secondary | Contrast, tension, buildup |

### Cycle Structure

```
{AABA} = complete cycle
{BA} = abbreviated return cycle
```

Notation: Curly brackets {} indicate formal cycles.

### Example: Beatles — "I Want to Hold Your Hand"

```
{AABA}:
0:00  Intro
0:08  Strophe 1 (A1)
0:29  Strophe 2 (A2)
0:51  Bridge (B)
1:11  Strophe 3 (A3)

{BA}:
1:33  Bridge (B)
1:53  Strophe 3 (A3)
```

Large-scale form: **{AABA}{BA}**

## Verse-Chorus Form (VC, VCB)

### Definition

Multiple core modules with different functions: verse carries narrative, chorus carries title/hook. Most dominant form since 1960s.

### Core Module Types

| Module | Abbrev. | Function |
|--------|---------|----------|
| Verse | V | Secondary; narrative text, begins song |
| Chorus | C | **Primary**; title lyrics, most memorable |
| Prechorus | P | Builds tension toward chorus |
| Bridge | B | Contrast; often replaces V in final cycle |
| Postchorus | Z | Extends chorus energy |

### Module Order

Modules always progress in this order (though not all need be present):

```
V → P → C → Z
     or
V → P → C → Z → B → C
```

### Common Cycles

| Cycle | Description |
|-------|-------------|
| {VC} | Basic verse-chorus |
| {VPC} | With prechorus buildup |
| {VVC} | Double verse (often first cycle) |
| {VPCZ} | Full cycle with postchorus |
| {BC} | Bridge cycle (usually final) |
| {BPC} | Bridge with prechorus |

### Example: Bon Jovi — "Livin' on a Prayer"

```
0:00  Extended Intro
0:47  Verse (V)
1:18  Prechorus (P)
1:34  Chorus (C)
---   [Mid-song intro]
1:54  Verse (V)
2:25  Prechorus (P)
2:41  Chorus (C)
2:56  Postchorus (Z)
3:00  Abbreviated final cycle
      Multiple chorus repeats → fadeout
```

## Simple Verse-Chorus Form

### Definition (Covach)

Verse and chorus share the same harmonic progression.

### Example: U2 — "With or Without You"

Same four-chord loop (D-A-Bm-G) underlies both verse and chorus sections.

## Super-Simple Verse-Chorus Form

### Definition (Summach)

Both harmonic progression AND melody are the same for verse and chorus.

## Module Classification

### Primary vs. Secondary

| Type | Module | Characteristics |
|------|--------|----------------|
| Primary | Chorus (VC), Strophe (AABA) | Title lyrics, most memorable |
| Secondary | Verse, Bridge | Narrative, contrast |

### Core vs. Auxiliary

| Type | Modules | Function |
|------|---------|----------|
| Core | V, C, P, B, Z | Main formal content |
| Auxiliary | Intro, Outro, Coda | Framing material |

## Analytical Notation

### Cycle Brackets

```
{AABA} = one complete AABA cycle
{VC}{VC}{BC} = three cycles
```

### Module Labels

```
V1, V2, V3 = verse instances
C, C', C'' = chorus with variations
```

## Compositional Application

### Choosing a Form

| Form | Best For |
|------|----------|
| Strophic | Story songs, folk influence, simplicity |
| AABA | Ballads, jazz standards, theatrical |
| Verse-Chorus | Pop/rock mainstream, hookdriven |
