# Rondo Form

## Summary

Rondo form alternates a recurring refrain with contrasting episodes. The refrain always returns in the tonic key, while episodes provide tonal and thematic contrast. Rondos are typically found in fast finales or slow second movements.

## Basic Concept

```
A - B - A - C - A ... (refrain - episode - refrain - episode - refrain)
```

| Element | Description |
|---------|-------------|
| Refrain (A) | Same material throughout, always in tonic |
| Episodes (B, C) | Contrasting material, different keys |

## Rondo Types

### Five-Part Rondo (ABACA)

The most common rondo structure.

```
A - B - A - C - A
```

| Section | Key | Function |
|---------|-----|----------|
| A (refrain) | I | Establish main theme |
| B (episode 1) | V or other | First contrast |
| A (refrain) | I | Return |
| C (episode 2) | Different from B | Second contrast |
| A (refrain) | I | Final return |

### Sonata-Rondo (ABACABA)

Combines rondo with sonata form principles.

```
A - B - A - C - A - B' - A
```

| Section | Key | Sonata Function |
|---------|-----|-----------------|
| A + B | I → V | Exposition |
| A | I | Refrain |
| C | Various | Development |
| A + B' | I → I | Recapitulation |
| A | I | Coda refrain |

**Key feature**: B returns transposed to tonic (like sonata S theme recapitulation).

## Refrain Characteristics

### Thematic Content

- Clear, memorable main theme
- Usually tight-knit (period or sentence)
- Same basic material each appearance
- May be slightly varied (embellished, abbreviated)

### Key

- ALWAYS in tonic
- No exceptions—this is definitive of rondo

### Variations

| Variation Type | Description |
|----------------|-------------|
| Embellished | Ornamental additions |
| Abbreviated | Shortened version |
| Extended | Added closing material |
| Reharmonized | Different harmonization |

## Episode Characteristics

### Thematic Content

- Contrasts with refrain
- Episodes B and C are usually different from each other
- May share some motivic material with refrain

### Key

- Must contrast with tonic
- Common keys: V, vi, IV, III (relative major in minor)
- Not restricted—any contrasting key works

### Structure

Episodes often have:
- Looser organization than refrain
- Modulatory passages
- Sequential writing
- Development-like character (especially C in sonata-rondo)

## Formal Templates

### Five-Part Rondo

```
A (mm. 1-16):     Refrain in I, ends I:PAC
B (mm. 17-32):    Episode in V, ends V:PAC or retransition
A (mm. 33-48):    Refrain in I
C (mm. 49-72):    Episode (developmental), ends with retransition
A (mm. 73-88):    Final refrain in I
```

### Sonata-Rondo

```
Exposition:
  A (mm. 1-16):   P function, I
  B (mm. 17-40):  S function, V

Refrain:
  A (mm. 41-56):  I

Development:
  C (mm. 57-80):  Developmental episode

Recapitulation:
  A (mm. 81-96):  I
  B' (mm. 97-120): S transposed to I

Coda:
  A (mm. 121-136): Final refrain, I
```

## Transitions and Retransitions

### Between Sections

| Transition | Function |
|------------|----------|
| A → B | Modulate to episode key |
| B → A | Retransition to tonic (often on V) |
| A → C | Modulate or move directly |
| C → A | Retransition, prepare final return |

### Retransition

- Prepares return of refrain
- Often dominant prolongation ("standing on the dominant")
- Creates anticipation for tonic return
- Similar to sonata retransition

## Comparison with Other Forms

| Feature | Five-Part Rondo | Sonata-Rondo | Sonata |
|---------|-----------------|--------------|--------|
| Refrain returns | Yes (3+ times) | Yes (3+ times) | No explicit refrain |
| Development | Episode C | Episode C | Yes |
| S recaps in I | N/A | Yes (B') | Yes |
| Typical location | Finale | Finale | First movement |

## Thematic Functions in Rondo

### Refrain Functions

1. **Opening**: Establish main idea
2. **Return**: Confirm tonic after contrast
3. **Closing**: Final affirmation

### Episode Functions

1. **Contrast**: Provide variety
2. **Tension**: Move away from tonic
3. **Development**: Transform material (especially C)

## Episode Types (Detail)

### Interior Theme

The simpler episode type, resembling a Minuet's Trio.

| Aspect | Description |
|--------|-------------|
| **Tonality** | Modal contrast (*minore*/*maggiore*) or tonal contrast |
| **Structure** | Usually rounded binary, may have repeats |
| **Ending** | May include retransition to dominant |

**Complications:**
- Recapitulation may not return (AAB + retransition)
- Recapitulation may merge into retransition without PAC

### Second-Theme Complex

More complex episode resembling sonata exposition zones (TR → S → CL → RT).

| Zone | Function | Key |
|------|----------|-----|
| TR | Modulate to subordinate key | Pivot |
| S | Confirm subordinate key with PAC | V or III |
| CL | Post-cadential | Subordinate |
| RT | Return to tonic dominant | → I:HC |

**Cadential Analysis Tips:**

| Situation | Interpretation |
|-----------|----------------|
| Phrase ends with PAC in subordinate key | S function |
| Phrase modulates but ends HC | TR function |
| Phrase follows subordinate PAC | CL function |
| Phrase contains I:HC + standing on V | RT function |

**Complications:**
- **TR⇒S merger**: Single phrase modulates AND confirms subordinate key with PAC
- **No TR**: Direct modulation, S appears immediately
- **S⇒RT merger**: S never achieves PAC, merges into retransition

### Episode Type Summary

| Type | Complexity | Key Relationship | Typical Structure |
|------|------------|------------------|-------------------|
| Interior theme | Simple | Modal (*minore*) | Rounded binary |
| Second-theme complex | Complex | Tonal (V, III) | TR-S-CL-RT zones |

## Compositional Application

### Designing a Five-Part Rondo

1. **Write refrain**: Strong, memorable, closed theme in I
2. **Create episode B**: Contrasting key and character
3. **Retransition**: Return to refrain
4. **Create episode C**: Different contrast, more developmental
5. **Final refrain**: May be extended or shortened

### Character Considerations

| Element | Typical Character |
|---------|-------------------|
| Refrain | Light, tuneful, memorable |
| Episode B | Contrasting but related |
| Episode C | More dramatic, developmental |
| Overall | Lighter than sonata first movements |

### Key Selection

| Mode | Episode B | Episode C |
|------|-----------|-----------|
| Major | V, vi, or IV | Different from B |
| Minor | III, v, or iv | Different from B |

## Constraints

1. **Refrain key**: Always tonic—no exceptions
2. **Episode contrast**: Must differ from refrain in key
3. **Minimum refrains**: At least 3 appearances of A
4. **B ≠ C**: Episodes should have distinct material

## Rondo vs. Variations

| Feature | Rondo | Theme & Variations |
|---------|-------|-------------------|
| Theme returns | Unchanged (mostly) | Varied each time |
| Contrasting material | Yes (episodes) | No (all variations of theme) |
| Key changes | Episodes in new keys | Usually same key |
