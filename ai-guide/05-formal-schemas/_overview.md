# Formal Schemas (Galant Schemata)

## Summary

Galant schemata are named melodic-harmonic patterns that recur throughout 18th-century music. Each schema has characteristic melody, bass, and harmony that can be combined to build phrases.

## Schema Categories

| Category | Function | Examples |
|----------|----------|----------|
| Opening | Begin phrases, prolong T | Meyer, Jupiter, Aprile |
| Continuation | Connect sections | Prinner, Fonte, Monte |
| Cadential | End phrases | Compound PAC/IAC/HC |

## Schema Notation Format

Each schema is described by:
- **Melody**: Scale degrees (do, re, mi...)
- **Bass**: Scale degrees
- **Harmony**: Roman numerals / Functions

## Key Schemas

### Opening Schemas

| Schema | Melody | Bass | Function |
|--------|--------|------|----------|
| Meyer | do-ti-fa-mi | do-re-ti-do | T-D-D-T |
| Jupiter | do-re-fa-mi | do-ti-ti-do | T-D-D-T |
| Aprile | do-ti-re-do | do-re-ti-do | T-D-D-T |
| Do-Re-Mi | do-re-re-mi | do-ti-ti-do | T-D-D-T |

### Continuation Schemas

| Schema | Melody | Bass | Function |
|--------|--------|------|----------|
| Prinner | la-sol-fa-mi | fa-mi-re-do | S-T-D-T |
| Fonte | Descending sequence | Model-copy | Sequential |
| Monte | Ascending sequence | Model-copy | Sequential |

### Cadential Schemas

| Schema | Melody | Bass | Result |
|--------|--------|------|--------|
| Compound PAC | mi-re-do | sol-sol-do | Strong close |
| Compound IAC | sol-fa-mi | sol-sol-do | Moderate close |
| fa-fi-sol HC | re-do-ti | fa-fi-sol | Half cadence |
