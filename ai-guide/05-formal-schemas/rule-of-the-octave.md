# Rule of the Octave and Cadential Schemas

## Summary

The Rule of the Octave is the partimento "cheat sheet" that assigns one chord to each degree of a stepwise bass scale, ascending and descending. This file gives v2's version (after Fenaroli, Naples 1775) in major and minor, plus v2's pre-cadential, cadential and post-cadential galant schemas that the other schema files lack.

## Schema Anatomy and Stage Meter

v2 defines a schema by **what** happens and **where** it is used.

| Component | Notation |
|-----------|----------|
| Melody | Scale degrees of the top voice per stage |
| Bass | Scale degrees of the bass per stage |
| Harmony | Figured-bass figures (Roman numerals are secondary) |
| Meter | Each stage marked **S** (strong beat of the bar) or **W** (weak beat) |
| Location | Opening gambit, continuation (answer/process/transition), pre-cadential, cadence, post-cadential |

- Stage meter is relative: it says which stages take the metrical accent, not which beat number.
- Two-stage schemas are typically W→S (e.g. Comma, the second half of the Meyer).
- Pace sets the formal role. With one stage per bar, a Meyer typically fills a presentation or antecedent. With two stages per bar, it forms a basic idea, typically answered by a closing gesture such as the Prinner.

## The Rule of the Octave

### How v2 builds it (from parallel 6/3s)

1. Harmonize every bass degree with 6/3.
2. Put 5/3 on the first and last *do* (tonic closure).
3. Put 5/3 on *sol* as well, ascending and descending.
4. Precede each tonic and dominant chord, including inversions, with a seventh chord. Exactly one of these is chromatic: ♯4 (*fi*) over *la* when descending, to tonicize the dominant.

v2 adjusts Fenaroli's version slightly to keep four voices throughout and to avoid any suggestion of parallels.

### Major (C major)

Ascending:

| Bass | Figure | Chord tones (C) | Function |
|------|--------|-----------------|----------|
| *do* (C) | 5/3 | C E G | I |
| *re* (D) | 6/4/3 | D F G B | V4/3 |
| *mi* (E) | 6/3 | E G C | I6 |
| *fa* (F) | 6/5/3 | F A C D | ii6/5 |
| *sol* (G) | 5/3 | G B D | V |
| *la* (A) | 6/3 | A C F | IV6 |
| *ti* (B) | 6/5/3 | B D F G | V6/5 |
| *do* (C) | 5/3 | C E G | I |

Descending:

| Bass | Figure | Chord tones (C) | Function |
|------|--------|-----------------|----------|
| *do* (C) | 5/3 | C E G | I |
| *ti* (B) | 6/3 | B D G | V6 |
| *la* (A) | ♯6/4/3 | A C D F♯ | V4/3 of V (the one chromatic chord) |
| *sol* (G) | 5/3 | G B D | V |
| *fa* (F) | 6/4/2 | F G B D | V4/2 |
| *mi* (E) | 6/3 | E G C | I6 |
| *re* (D) | 6/4/3 | D F G B | V4/3 |
| *do* (C) | 5/3 | C E G | I |

### Minor (A minor)

v2's score uses the melodic-minor bass: *la* and *ti* raised going up, *le* and *te* going down. *ti* is raised in every dominant chord in both directions.

Ascending:

| Bass | Figure | Chord tones (a) | Function |
|------|--------|-----------------|----------|
| *do* (A) | 5/3 | A C E | i |
| *re* (B) | ♯6/4/3 | B D E G♯ | V4/3 |
| *me* (C) | 6/3 | C E A | i6 |
| *fa* (D) | 6/5/3 | D F A B | iiø6/5 |
| *sol* (E) | ♯5/3 (major 3rd) | E G♯ B | V |
| *la* (F♯) | 6/3 | F♯ A D | IV6 (raised 6th degree) |
| *ti* (G♯) | 6/5/3 | G♯ B D E | V6/5 |
| *do* (A) | 5/3 | A C E | i |

Descending:

| Bass | Figure | Chord tones (a) | Function |
|------|--------|-----------------|----------|
| *do* (A) | 5/3 | A C E | i |
| *te* (G) | 6/3 | G B E | v6 (minor v, no leading tone) |
| *le* (F) | ♯6/4/3 | F A B D♯ | Fr+6 (*le–do–re–fi*), i.e. V7/V with its lowered 5th in the bass; minor counterpart of major's V4/3 of V |
| *sol* (E) | ♯5/3 | E G♯ B | V |
| *fa* (D) | 6/♯4/2 | D E G♯ B | V4/2 |
| *me* (C) | 6/3 | C E A | i6 |
| *re* (B) | ♯6/4/3 | B D E G♯ | V4/3 |
| *do* (A) | 5/3 | A C E | i |

Major vs. minor: the figure numbers are the same at every degree. Minor adds accidentals for the leading tone and, descending, the ♯6 over *le*.

### Positions (v2 "Part by Part")

Fenaroli's three "positions" are the three inversions of the right-hand chord. They are named by what the top voice centres on:

| Position | Top voice on the first chord |
|----------|------------------------------|
| First | *do* |
| Second | *mi* |
| Third | *sol* |

### Variants: harmonizing the bass scale with sequences (v2 02/13)

| Pattern | Ascending bass | Descending bass |
|---------|----------------|-----------------|
| Parallel 6/3 | 6/3 on every degree | Same |
| 5–6 | Alternate 5th and 6th above each bass note | Alternate 5–6 on each note, or 5 and 6 on separate notes (v2's file uses the latter) |
| 7–6 suspension chain | Upper voice must jump up an octave to restart, so the unit is 7–6–8 | No change needed: delayed parallel 6/3s |
| Circle of fifths | Ascending version with 4–3 suspensions | Root down a 5th, up a 4th; alternate bass notes form a descending scale. Versions: triads only; with 7ths and suspensions; "zigzag" with outer-voice canon |
| 2–3 suspension chain (inversion of 7–6) | Restart needed: 2–3–1 in the upper part, 9–8–10 against the bass | No restart; yields a diatonic chain of 4/2 → 6 (like V4/2–I6 without tonicizing each step) |

## Pre-Cadential Schemas

| Schema | Stage | 1 | 2 | 3 | 4 | 5 |
|--------|-------|---|---|---|---|---|
| **Fenaroli** | Meter | S | W | S | W | |
| | Melody | *fa* | *mi* | *ti* | *do* | |
| | Bass | *ti* | *do* | *re* | *mi* | |
| | Figures | 6/5 | 5 | 6 | 6 | |
| | RN | V6/5 | I | vii°6 (dominant) | I6 | |
| **Indugio** | Meter | S | W | S | W | S |
| | Melody | *re* | *fa* | *la* | *do* | *ti* |
| | Bass | *fa* | *fa* | *fa* | *fi* | *sol* |
| | Figures | 6/5 | 6/5 | 6/5 | 6/5 | 5 |
| | RN | ii6/5 (v2: "IV") | ii6/5 | ii6/5 | V6/5/V | V |
| **Comma** | Meter | W | S | | | |
| | Melody | *fa* | *mi* | | | |
| | Bass | *ti* | *do* | | | |
| | Figures | 6/5 | 5 | | | |
| | RN | V6/5 | I | | | |
| **Converging cadence** | Meter | W | S | W | S | |
| | Melody | *mi* | *re* | *do* | *ti* | |
| | Bass | *mi* | *fa* | *fi* | *sol* | |
| | Figures | 6 | 6/5 | 6/5 | 5 | |
| | RN | I6 | ii6/5 | V6/5/V | V (HC) | |

- **Fenaroli**: two linked V–I pairs. The bass rises *ti–do–re–mi* against the melody *fa–mi–ti–do*. v2's itemized table gives 6/5 on stage 3; v2's summary row and score give 6. Both are dominant chords over *re*.
- **Indugio** ("delay"): a prolonged *fa* bass under a rising arpeggiation (*re–fa–la–do*), then *fi–sol*. v2 points out its correspondence with the converging cadence. The 6/5 on *fa* contains *fa la do re*.
- **Comma**: a two-stage V6/5–I. It is identical to the closing half of the Meyer and to the model unit of the Fonte.
- **Converging cadence**: also called the *fa–fi–sol* half cadence. The outer voices converge on *ti*/*sol*.

## Cadences

| Schema | Stage | 1 | 2 | 3 | 4 | 5 |
|--------|-------|---|---|---|---|---|
| **Cadenza semplice** | Meter | W | S | W | S | |
| | Melody | *do* | *re* | *re* | *do* | |
| | Bass | *mi* | *fa* | *sol* | *do* | |
| | Figures | 6 | 6/5 | 5 | 5 | |
| | RN | I6 | ii6/5 | V | I | |
| **Cadenza composta** | Meter | W | S | S | W | S |
| | Melody | *do* | *re* | *mi* | *re* | *do* |
| | Bass | *mi* | *fa* | *sol* | *sol* | *do* |
| | Figures | 6 | 6/5 | 6/4 | 7 | 5 |
| | RN | I6 | ii6/5 | cad. 6/4 | V7 | I |
| **Cadenza doppia** | Meter | S | W | S | W | S |
| | Melody | *re* | *mi* | *re* | *re* | *do* |
| | Bass | *sol* | *sol* | *sol* | *sol* | *do* |
| | Figures | 5 | 6/4 (6/4/2 in v2's score) | 5/4 | 5/3 | 5 |
| | RN | V | (V) | (V) | V | I |

- **Semplice vs. composta**: the composta inserts a cadential 6/4 on *sol*, which turns the melody into *mi–re–do* over *sol–sol–do*. Its 6/4 and 7 share one bar in v2's score (6/4 on the downbeat, 7 at mid-bar).
- **Doppia**: a four-stage dominant over a held *sol*. An upper voice moves 4–3 against it, and the melody rises *re–mi* and falls back to *re–do*. v2's tables print the doppia melody as *fa–mi–re–re–do*. That cannot match figure 5 on stage 1 (*fa* over *sol* is a 7th), and v2's score has *re–mi–re–re–do*, so this file follows the score.
- **Deceptive and evaded cadences** keep the semplice's first three stages (W S W: *do–re–re* over *mi–fa–sol*, 6 – 6/5 – 5) and change stage 4 (S):

| Variant | Stage 4 melody | Stage 4 bass | Figure | RN |
|---------|----------------|--------------|--------|----|
| Deceptive cadence | *do* | *la* | 5 | vi |
| Evaded cadence | *do* | *mi* | 6 | I6 |

## Post-Cadential: Quiescenza

| Stage | 1 | 2 | 3 | 4 |
|-------|---|---|---|---|
| Meter | W | S | W | S |
| Melody | *te* | *la* | *ti* | *do* |
| Bass | *do* | *do* | *do* | *do* |
| Figures | ♭7 | 6/4 | 7/4/2 | 5 |
| Chord | I♭7 = V7/IV | IV6/4 | vii° (*ti re fa*) over the pedal | I |

- A tonic pedal follows a cadence. The upper voice falls chromatically *do–te–la*, then rises *la–ti–do*.
- v2 labels stage 2 "V". Its 6/4 on *do* is *do fa la*, which is IV6/4, and v2's score has F–A–C there. Stage 3 holds the dominant-function chord.

## Constraints

1. Rule of the Octave, major: 5/3 only on *do* and *sol*. Ascending *re* 6/4/3, *mi* 6/3, *fa* 6/5/3, *la* 6/3, *ti* 6/5/3. Descending *ti* 6/3, *la* ♯6/4/3, *fa* 6/4/2, *mi* 6/3, *re* 6/4/3.
2. The only chromatic note in the major rule is *fi* in the chord over descending *la*.
3. Minor: same figures; raise *ti* in every dominant chord. Ascending *la*/*ti* raised, descending *te*/*le* natural; ♯6 over *le* descending.
4. Every tonic or dominant chord in the rule is preceded by a seventh chord (V4/3, ii6/5, V6/5; descending V4/3 of V, V4/2, V4/3).
5. Stage meter: label each stage S or W; two-stage V→I modules (Comma) run W→S.
6. Cadenza composta = semplice + cadential 6/4 (*mi–re–do* over *sol–sol–do*). Cadenza doppia holds *sol* for four stages with a 4–3.
7. Deceptive and evaded cadences replace the semplice's final *do* bass with *la* (vi) or *mi* (I6).
8. Quiescenza: tonic pedal; upper line *do–te–la–ti–do*; post-cadential only.
