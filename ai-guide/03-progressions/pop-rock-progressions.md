# Pop/Rock Progressions

## Summary

Pop/rock harmony is characterized by cyclical four-chord progressions (loops) that repeat throughout sections. These stock progressions recur across thousands of songs.

**Superseded in part by [Pop Harmonic Schemas](pop-schemas.md)** (OMT 2e, `v2/07-popular-music/08`–`15`). That file adds hopscotch (IV–V–vi–I), the plagal sigh, the modal shuttles and cadences, and the mode flowchart, with v2's names and functions. Where the two files differ, follow pop-schemas.md. The lament, shuttle and Puff entries here were corrected to match it.

## Major Key Progressions

### 50s Doo-Wop

**Pattern:** `I - vi - IV - V` or `I - vi - ii - V`

| Feature | Description |
|---------|-------------|
| Function | T - T - S - D |
| Character | Nostalgic, ballad-like |
| Era | 1950s-60s, still common |

**Rotations:**
- `IV - V - I - vi` (start on IV)
- `vi - IV - V - I` (start on vi)

### Singer/Songwriter (Axis)

**Pattern:** `vi - IV - I - V`

| Feature | Description |
|---------|-------------|
| Function | T - S - T - D |
| Character | Emotional, introspective |
| Era | 1990s onwards |

**Rotations:**
- `I - V - vi - IV` (start on I, "Axis of Awesome")
- `IV - I - V - vi` (deceptive variant)

**Mode ambiguity:** Same chords work as:
- Major: `vi - IV - I - V` in C = Am-F-C-G
- Minor: `i - VI - III - VII` in Am = Am-F-C-G

### Pachelbel

**Pattern:** `I - V - vi - iii - IV - I - IV - V`

| Feature | Description |
|---------|-------------|
| Length | 8 chords (double cycle) |
| Bass | Descending then ascending |
| Character | Grand, emotional |

**Truncated:** `I - V - vi - iii...` (first 4 chords)

**Inverted variant:** `I - V6 - vi - iii6 - IV - I6 - IV - V`

### Plagal Oscillation (I-IV)

**Pattern:** `I - IV` (two-chord oscillation)

| Feature | Description |
|---------|-------------|
| Function | T - S |
| Character | Simple, folk-like |
| Origin | Shuffle-blues guitar patterns |

**Examples:** "Soul Man" (Sam & Dave), "In the Midnight Hour" (Wilson Pickett)

### Double-Plagal

**Pattern:** `bVII - IV - I`

| Feature | Description |
|---------|-------------|
| Function | S - S - T |
| Character | Expansive, triumphant |
| Motion | Descending fourths (bVII→IV→I) |

**Alternative interpretations:**
- "IV of IV" (applied subdominant)
- Modal mixture (borrowed from Mixolydian)
- Plagal chain by root motion

**In minor:** `bVII - iv - i` (bVII is major, borrowed)

**Example:** "Hey Jude" coda (The Beatles)

### Extended Plagal

**Pattern:** `bVI - bIII - bVII - IV - I`

| Feature | Description |
|---------|-------------|
| Motion | Descending fourths chain |
| Character | Epic, building |
| Theory | Series of borrowed major chords / modal mixture |

*Note: Sometimes described as "chained applied IV" but more commonly viewed as modal borrowing or circle-of-fourths motion.*

**Example:** "Hey Joe" verse (Jimi Hendrix)

### Puff (I–iii–IV)

**Pattern:** `I - iii - IV ...` (phrase opener; not usually looped)

| Feature | Description |
|---------|-------------|
| Function | T - T - S |
| Position | Opening of phrases; what follows IV varies (I, V, ...) |
| Character | Folk, narrative |

**Key feature:** the bass moves do–mi–fa, and mi is harmonized as a root-position **iii** (minor), not as I6.

**Variants (OMT 2e, `v2/07-popular-music/12-puff-schemas.md`):**
- `I - III♯ - IV`: iii's third is raised, making a major III♯ with the inner line sol–si–la (e.g. Radiohead, "Creep": G–B–C–Cm, I–III♯–IV–iv).
  - III♯ can also be heard as V/vi. III♯–IV is then a deceptive resolution of V/vi.
- Minor: `i - III - iv`, or with major IV: "House of the Rising Sun" is i–III–IV–VI | i–III–V (Am–C–D–F | Am–C–E).

**Examples:** "Puff, the Magic Dragon" (A–C♯m–D–A = I–iii–IV–I), Marvin Gaye "Let's Get It On" (I–iii7–IV–V11), "House of the Rising Sun" (minor)

*Correction note: an earlier version of this file gave the Puff as I–III–IV, with major III in "Puff". The song has minor iii (C♯m in A). III♯ is a variant.*

### Circle of Fifths

**Pattern:** `vi - ii - V - I` or extended

| Feature | Description |
|---------|-------------|
| Function | Falling fifths |
| Character | Jazz-influenced, sophisticated |
| Bass | Root moves down P5 |

## Minor Key Progressions

### Lament

**Pattern:** `i - ♭VII - ♭VI - V`

| Feature | Description |
|---------|-------------|
| Function | T - D - S - D |
| Character | Sad, descending |
| Origin | Baroque ground bass |

**Bass line:** do–te–le–sol (the descending minor tetrachord, v2 07/11). The chromatic form fills in the semitones.

**Variants (v2 07/08):** i–♭VII–♭VI–v (aeolian lament, no leading tone); major I in place of i; passing V6 or IV6 between chords. "Andalusian cadence" is another name for this progression, not a separate schema.

### Aeolian Shuttle

**Pattern:** `i - ♭VII - ♭VI - ♭VII` (OMT 2e, `v2/07-popular-music/13-modal-schemas.md`)

| Feature | Description |
|---------|-------------|
| Mode | Natural minor (Aeolian) |
| Shape | a shuttle between i and ♭VI, with passing ♭VII; circular, no cadence |
| No V-i | ♭VII stands in for the dominant |

- The two-chord **i–♭VII** (or ♭VII–i) is the **subtonic shuttle** (aeolian version), not the aeolian shuttle.
- **♭VI–♭VII–i** (usually ♭VI–♭VII–I) is the goal-directed **aeolian cadence**.
- *Correction note: an earlier version gave the aeolian shuttle as "i–VII or i–VI–VII".*

### Minor Plagal

**Pattern:** `i - iv - i` or `i - iv - VII - i`

| Feature | Description |
|---------|-------------|
| Function | T - S - T |
| Character | Heavy, rock |

## Rotation Principle

All cyclical progressions can begin on any chord:

| Progression | Rotation 1 | Rotation 2 | Rotation 3 | Rotation 4 |
|-------------|-----------|-----------|-----------|-----------|
| Doo-wop | I-vi-IV-V | vi-IV-V-I | IV-V-I-vi | V-I-vi-IV |
| SSCP | vi-IV-I-V | IV-I-V-vi | I-V-vi-IV | V-vi-IV-I |

## Compositional Application

### Choosing a Progression

| Desired Effect | Progression |
|----------------|-------------|
| Nostalgic/classic | 50s Doo-wop |
| Emotional/modern | Singer/Songwriter |
| Grand/epic | Pachelbel |
| Simple/folk | Plagal oscillation (I-IV) |
| Triumphant/anthemic | Double-plagal (bVII-IV-I) |
| Building/climactic | Extended plagal |
| Dark/heavy | Lament, Aeolian |
| Narrative/opening | Puff (I–iii–IV) |
| Sophisticated | Circle of fifths |

### Extending Progressions

1. **Loop:** Repeat 4-chord pattern
2. **Rotate:** Start loop on different chord
3. **Truncate:** Use first 2-4 chords only
4. **Combine:** Mix progressions between sections

### Section Mapping

| Section | Common Progressions |
|---------|-------------------|
| Verse | Doo-wop, SSCP, Lament |
| Chorus | SSCP (I-V-vi-IV), Pachelbel |
| Bridge | Different rotation or new progression |
| Outro | Same as chorus or simplified |

## Constraints

1. **Loop length:** Usually 4 or 8 chords
2. **Root position:** Most chords in root position
3. **7th chords:** Less common than classical
4. **Voice-leading:** Less strict than classical
