# Harmonic Progressions

## Summary

Stock progressions are recurring chord patterns that form the harmonic foundation of songs across genres. Learning these patterns enables efficient composition and analysis.

## Progression Types

| Type | Style | Characteristics |
|------|-------|-----------------|
| Classical | Common-practice | Function-based, cadential |
| Pop/Rock | Popular music | Cyclical, loop-based |
| Blues | Blues/Jazz | 12/16-bar structure |
| Modal | Various | Non-functional, color-based |

## Common Stock Progressions

### Most Frequent (Pop/Rock)

| Name | Progression | Function |
|------|-------------|----------|
| 50s Doo-Wop | I-vi-IV-V | T-T-S-D |
| Singer/Songwriter | vi-IV-I-V | T-S-T-D |
| Axis | I-V-vi-IV | T-D-T-S |
| Plagal | I-IV | T-S |

### Classical

| Name | Progression | Function |
|------|-------------|----------|
| Basic | I-IV-V-I | T-S-D-T |
| Circle of 5ths | I-IV-vii°-iii-vi-ii-V-I | Full cycle |
| Romanesca | I-V-vi-III-IV-I-IV-V | Descending thirds |

### Blues-Based

| Name | Progression |
|------|-------------|
| 12-Bar Blues | I×4, IV×2-I×2, V-IV-I×2 |
| 16-Bar Blues | I×8, IV×2-I×2, V-IV-I×2 |
