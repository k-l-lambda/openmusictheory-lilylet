# Classical Progressions

## Summary

Classical progressions follow the T-S-D-T functional cycle. Unlike pop/rock loops, classical progressions are goal-directed toward cadences and follow strict voice-leading conventions.

## Core Principle

### The Functional Cycle

```
T → S → D → T → (repeat)
```

Movement follows the cycle forward. Backward motion (D→S) is rare and marked.

### Idealized Phrase

Every complete phrase moves through:

```
T1 → (S) → D5 → T1
```

Where S is optional but D5→T1 (authentic cadence) is required for closure.

## Basic Progressions

### Minimum Phrase

| Progression | Function | Notes |
|-------------|----------|-------|
| I-V-I | T-D-T | Minimum complete phrase |
| I-V7-I | T-D-T | With dominant seventh |

### With Subdominant

| Progression | Function | Notes |
|-------------|----------|-------|
| I-IV-V-I | T-S-D-T | Standard with IV |
| I-ii-V-I | T-S-D-T | Standard with ii |
| I-ii6-V-I | T-S-D-T | ii6 more common than ii |
| I-IV-V7-I | T-S-D-T | With dominant seventh |

### With Pre-Dominant Elaboration

| Progression | Function | Notes |
|-------------|----------|-------|
| I-IV-ii-V-I | T-S-S-D-T | S zone extended |
| I-vi-ii-V-I | T-T-S-D-T | Tonic prolongation to ii |
| I-vi-IV-V-I | T-T-S-D-T | vi as tonic associate |

## Circle of Fifths Progressions

### The Full Circle

Roots descend by fifth (or ascend by fourth):

```
I → IV → viio → iii → vi → ii → V → I
```

### Common Segments

| Segment | Progression | Usage |
|---------|-------------|-------|
| Short | vi-ii-V-I | Very common approach |
| Medium | iii-vi-ii-V-I | Extended pre-dominant |
| Full | I-IV-viio-iii-vi-ii-V-I | Complete circle |

### Circle in Minor

```
i → iv → VII → III → VI → iio → V → i
```

## Cadential Progressions

### Approaching PAC

| Approach | Progression | Quality |
|----------|-------------|---------|
| ii-V-I | S-D-T | Standard |
| IV-V-I | S-D-T | Standard |
| ii6-cad6/4-V-I | S-D-D-T | With cadential 6/4 |
| IV-cad6/4-V-I | S-D-D-T | With cadential 6/4 |
| vi-ii-V-I | T-S-D-T | Extended approach |

### Approaching HC

| Approach | Progression | Notes |
|----------|-------------|-------|
| I-ii-V | T-S-D | Standard |
| I-IV-V | T-S-D | Standard |
| I-vi-ii-V | T-T-S-D | Extended |
| I-ii6-cad6/4-V | T-S-D-D | With cadential 6/4 |

### Deceptive Cadence

| Expected | Actual | Effect |
|----------|--------|--------|
| V-I | V-vi | Thwarted resolution |
| V7-I | V7-vi | Requires phrase extension |

## Functional Substitutions

### Tonic Family

| Primary | Substitutes | Bass |
|---------|-------------|------|
| I | vi, iii | 1, 6, 3 |
| I6 | iii | 3 |

### Subdominant Family

| Primary | Substitutes | Bass |
|---------|-------------|------|
| IV | ii, ii6 | 4, 2, 4 |
| ii6 | IV | 4 |

### Dominant Family

| Primary | Substitutes | Bass |
|---------|-------------|------|
| V | viio, V7 | 5, 7, 5 |
| V7 | viio7 | 5, 7 |

## Voice-Leading Considerations

### Root Motion Preferences

| Motion | Quality | Example |
|--------|---------|---------|
| Down 5th (up 4th) | Strong | V-I, ii-V |
| Down 3rd | Good | I-vi, IV-ii |
| Up 2nd | Acceptable | IV-V, I-ii |
| Up 3rd | Weak | vi-I (retrogression) |
| Down 2nd | Weak | V-IV (retrogression) |

### Bass Line Principles

| Principle | Application |
|-----------|-------------|
| Stepwise preferred | Use inversions for smooth bass |
| Avoid large leaps | Except octave or fifth |
| Approach cadence by step | ii6-V or IV-V |

## Common Classical Formulas

### Opening Gambit

```
I - V6 - I6    (Tonic prolongation)
I - viio6 - I6    (Passing diminished)
I - IV6 - I6    (Champagne progression)
```

### Pre-Cadential Intensification

```
IV - ii6 - cad6/4 - V    (S intensification)
vi - ii - cad6/4 - V    (Extended approach)
```

### Lament Bass (Minor)

```
i - v6 - iv6 - V    (Descending tetrachord)
i - VII - VI - V    (Root position variant)
```

## Phrase Models

### 4-Bar Phrase

```
| I     | ii6   | V     | I     |
| T     | S     | D     | T     |
```

### 8-Bar Period Antecedent

```
| I     | vi    | ii6   | V     |
| T     | T     | S     | D (HC)|
```

### 8-Bar Period Consequent

```
| I     | vi    | ii6-V | I     |
| T     | T     | S-D   | T (PAC)|
```

## Compositional Application

### Building a Classical Phrase

1. **Establish tonic** — Begin on I (T1)
2. **Prolong or move to S** — vi-ii or IV
3. **Approach dominant** — ii6 or IV to V
4. **Cadence** — V-I (PAC) or end on V (HC)

### Avoiding Common Errors

| Error | Correction |
|-------|------------|
| D before S | Reorder: S then D |
| Weak cadence | Strengthen with ii6-V-I |
| Static harmony | Add passing/neighbor chords |
| Predictable | Use substitutions |

## Comparison with Pop Progressions

| Feature | Classical | Pop/Rock |
|---------|-----------|----------|
| Goal | Cadence | Loop |
| Direction | Forward (T-S-D-T) | Circular |
| Voice-leading | Strict | Flexible |
| Inversions | Common | Rare |
| 7ths | Functional | Color |
| Retrogression | Avoided | Common |
