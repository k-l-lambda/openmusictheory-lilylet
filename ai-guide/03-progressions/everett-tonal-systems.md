# Everett's Six Tonal Systems for Pop/Rock

## Summary

Walter Everett's six tonal systems provide a framework for analyzing the diverse harmonic languages found in pop and rock music. These systems range from classical common-practice tonality to modal, blues-based, and pentatonic approaches.

## System Overview

| System | Name | Basis | Key Features |
|--------|------|-------|--------------|
| 1 | Common Practice | Major/minor | Classical T-S-D function |
| 2 | Modal | Diatonic modes | ♭VII as primary dominant |
| 3 | Modal Borrowing | Hybrid | Major + Aeolian borrowing |
| 4 | Blues-Based | Blues scale | V-IV-I, 12/16-bar patterns |
| 5 | Pentatonic | Minor pentatonic | Power chords on I-♭III-IV-V-♭VII |
| 6 | Chromatic | Free chromaticism | Non-functional voice leading |

## System 1: Common Practice

Classical major/minor tonality applied to pop/rock.

**Characteristics:**
- Standard T-S-D functional progressions
- V resolves to I
- Leading tone present
- ii-V-I and IV-V-I common

**Context:** Many pre-1960s pop, ballads, musical theater influenced songs.

## System 2: Diatonic Modes

Draws on Western folk modal traditions (not Medieval church modes).

### Common Modes

| Mode | Scale | Characteristic Chords |
|------|-------|----------------------|
| Dorian | do-re-me-fa-sol-la-te | i, III, ♭VII |
| Mixolydian | do-re-mi-fa-sol-la-te | I, v, ♭VII |
| Aeolian | do-re-me-fa-sol-le-te | i, ♭VI, ♭VII |

*(Lydian rare; Locrian very rare due to diminished 5th; Phrygian typically in System 5)*

### Characteristic Harmonies

- **♭VII** = primary "dominant" (replaces V)
- **♭VI** = common in Aeolian
- **♭III** = common in Dorian/Aeolian

### Examples

- **Dorian:** Simon & Garfunkel — "Scarborough Fair" (i-III-♭VII)
- **Aeolian:** Simon & Garfunkel — "The Sound of Silence"
- **Mixolydian:** U2 — "In God's Country" (I-v alternation)
- **Aeolian:** U2 — "Sunday, Bloody Sunday" (i-III-♭VI)

## System 3: Modal Borrowing

Hybrid between System 1 and System 2 — major key with Aeolian borrowings.

### Typical Pattern

```
Major key tonic (I) + borrowed ♭VI, ♭VII, v
```

### Common Progressions

```
♭VI - ♭VII - I    (Aeolian cadence in major)
I - v - ♭VI - ♭VII
```

### Examples

- **Radiohead — "Everything in its Right Place":** Major I with v, ♭VI, ♭VII
- **Rolling Stones — "Brown Sugar":** I-IV-V with ♭VI-♭VII-I tag

## System 4: Blues-Based

Harmony derived from blues progressions and their descendants.

### Key Features

- **V-IV-I** motion (reverse classical)
- 12-bar and 16-bar patterns
- Dominant 7th quality on all chords

### Blues Legacy in Rock

```
Standard rock ending: I - V - IV - I
```

### Examples

- **Beatles — "Let It Be":** Ends I-V-IV-I (8-chord cycle)
- See [Blues Progressions](blues-progressions.md) for full 12/16-bar patterns

## System 5: Minor Pentatonic

Power chords or major triads on pentatonic scale degrees.

### Scale Degrees

**Standard rotation:**
```
I - ♭III - IV - V - ♭VII
```

**Rotated version:**
```
I - ♭III - IV - ♭VI - ♭VII  (V replaced by ♭VI)
```

### Phrygian Extension

In metal/hardcore, add **♭II** to pentatonic framework:
```
I - ♭II - ♭III - IV - V - ♭VI - ♭VII
```

### Examples

- **Beatles — "Sgt. Pepper's":** Chorus uses I-♭III-IV (all major)
- **Nirvana — "Smells Like Teen Spirit":** I-IV-♭III-♭VI power chord cycle
- **Shelter — "The Message of the Bhagavat":** Phrygian with ♭II

## System 6: Chromatic

Non-functional chromatic voice leading; chords connected by step motion rather than functional gravity.

*(Less common in mainstream pop/rock; more prevalent in art rock, progressive rock)*

## Analytical Application

### Identifying the System

1. **Check for V-I cadences** → System 1 or 3
2. **♭VII as dominant substitute?** → System 2, 3, or 5
3. **V-IV-I motion?** → System 4
4. **Power chords on pentatonic scale?** → System 5
5. **Stepwise chromatic movement?** → System 6

### System Mixing

Songs often combine systems:
- Verse in System 2, chorus in System 1
- System 4 blues with System 3 borrowing
- System 5 verse with System 2 modal chorus

## Compositional Application

### When to Use Each System

| System | Best For |
|--------|----------|
| 1 | Ballads, theatrical, sophisticated pop |
| 2 | Folk-influenced, Celtic, 60s-70s rock |
| 3 | Modern rock, adds edge to major key |
| 4 | Blues-rock, classic rock, R&B |
| 5 | Hard rock, metal, grunge, punk |
| 6 | Progressive rock, art rock |
