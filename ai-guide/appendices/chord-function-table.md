# Chord Function Quick Reference

## Major Key Functions

| Function | Primary | Associates | Dissonances |
|----------|---------|------------|-------------|
| **Tonic (T)** | I | vi, iii | — |
| **Subdominant (S)** | IV | ii | ii7, IV7 |
| **Dominant (D)** | V | viio | V7, viio7 |

## Minor Key Functions

| Function | Primary | Associates | Dissonances |
|----------|---------|------------|-------------|
| **Tonic (T)** | i | VI, III | — |
| **Subdominant (S)** | iv | iio | ii°7, iv7 |
| **Dominant (D)** | V | viio | V7, viio7 |

## Function Flow

```
T → S → D → T
T → D → T (direct)
```

**Prohibited**: D → S (without T in between)

## Scale Degree Tendencies

| Degree | Name | Tendency | Resolution |
|--------|------|----------|------------|
| 1 (do) | Tonic | Stable | — |
| 2 (re) | Supertonic | Unstable | 1 or 3 |
| 3 (mi) | Mediant | Stable | — |
| 4 (fa) | Subdominant | Unstable | 3 |
| 5 (sol) | Dominant | Stable | — |
| 6 (le/la) | Submediant | Mildly unstable | 5 |
| 7 (ti) | Leading tone | Very unstable | 1 |

## Cadence Types

| Cadence | Progression | Strength |
|---------|-------------|----------|
| PAC | V-I (both root pos., soprano on 1) | Strongest |
| IAC | V-I (inversion or soprano not on 1) | Moderate |
| HC | ...→V | Open |
| DC | V-vi | Deceptive |
| PC | IV-I | Plagal |

## Augmented Sixth Chords

| Type | Structure | Resolution |
|------|-----------|------------|
| Italian | le-do-fi | V |
| French | le-do-re-fi | V |
| German | le-do-me-fi | Cad.6/4 → V |

**Bass**: le (b6)
**Resolution**: fi→sol, le→sol

## Voice-Leading Essentials

| Rule | Description |
|------|-------------|
| Resolve ti | ti→do (up by step) |
| Resolve 7ths | Down by step |
| No parallel 5ths/8ves | Consecutive P5 or P8 in same direction |
| No direct 5ths/8ves | Similar motion to P5/P8 in outer voices |
| Double root | Normally double root of chord |
