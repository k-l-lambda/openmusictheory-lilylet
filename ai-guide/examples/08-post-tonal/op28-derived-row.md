# Webern, String Quartet Op. 28: a row derived from (0123), with (01) dyads

A row whose discrete segments all belong to one set class. Topic: [Twelve-Tone Technique](../../08-post-tonal/twelve-tone.md). Notation: [reading lilylet](../lilylet-primer.md).

## What to look for

- **The row:** P7 = G F♯ A G♯ | C D♭ B♭ B | E♭ D F E = 7 6 9 8 0 1 10 11 3 2 5 4.
- **Lower voice:** beamed in fours, stems down. These are the three **discrete tetrachords**, {6,7,8,9}, {10,11,0,1} and {2,3,4,5}. Each is a chromatic tetrachord **(0123)**, so the row is *tetrachordally derived* ("generated by (0123)").
- **Upper voice:** the same 12 notes beamed in pairs, stems up. These are the six **discrete dyads**, each a semitone **(01)**: the page's dyadic derivation.
- **Why it matters:** set-class content doesn't change under row operations, so (0123) and (01) keep recurring whatever row forms a piece uses. The page calls this a source of unity.
- **Notation:** both voices carry the same pitches. Verovio draws each shared note as one notehead with two stems, as the original does.
