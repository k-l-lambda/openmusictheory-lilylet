# Score Examples

Score examples for the topics in this guide. Each one is a lilylet transcription of a figure from Open Music Theory, checked bar by bar against the original image. Every example has YAML frontmatter (`id`, `topics`, `tags`, `key`, `meter`, `source_image`, `source_page`, `lilylet`, `provenance`) and a **What to look for** section that ties the concept to specific bars and notes.

- How to read the notation: [lilylet primer](lilylet-primer.md). For the full language, see the [Lilylet tutorial (plain text)](https://raw.githubusercontent.com/k-l-lambda/lilylet-live-editor/refs/heads/main/static/docs/lilylet-tutorial.md).
- `provenance: omr` means the example was transcribed by STARRY OMR and then corrected bar by bar; `hand` means it was written by hand. Both kinds were reviewed against the original image.
- Each score block is generated from its source file under `Graphics/lilylet/`. Run `npx tsx ai-guide/examples/sync.mjs` after a source changes; `--check` fails when a block is out of date or doesn't parse.
