# Chromatic Harmony

## Summary

Chromatic harmony extends diatonic function through borrowed tones, secondary dominants, and altered chords while maintaining tonal coherence.

## Types of Chromatic Chords

| Type | Mechanism | Function |
|------|-----------|----------|
| Applied Chords | Borrow from target key | Dominant of non-tonic chord |
| Modal Mixture | Borrow from parallel mode | Same function, different color |
| Augmented Sixth | Chromatic approach to V | Intensified subdominant |
| Neapolitan | bII chord | Subdominant substitute |

## Chromatic Scale Degrees

| Diatonic | Raised | Lowered | Common Use |
|----------|--------|---------|------------|
| 1 (do) | di | - | V/ii |
| 2 (re) | ri | ra | V/iii, bII |
| 4 (fa) | fi | - | V/V |
| 5 (sol) | si | - | V/vi |
| 6 (la) | li | le | Modal mixture |
| 7 (ti) | - | te | Modal mixture |

## Compositional Application

Chromatic harmony provides:
1. **Color** - Richer harmonic palette
2. **Intensity** - Stronger directional motion
3. **Surprise** - Deviation from expectation
4. **Modulation** - Pathway to new keys
