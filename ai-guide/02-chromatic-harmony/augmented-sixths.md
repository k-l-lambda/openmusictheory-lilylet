# Augmented-Sixth Chords

## Summary

Augmented-sixth chords are chromatic subdominant chords named for the augmented sixth interval between le and fi. They intensify pre-dominant function and resolve to V (often via cadential 6/4).

## Core Concept

### Defining Interval

All augmented-sixth chords contain:
- **le** (lowered 6) in the bass
- **fi** (raised 4) in an upper voice
- Interval le-fi = augmented sixth (expands to octave on sol)

### Function

- **Always subdominant function** [S]
- Intensified pre-dominant leading to V
- The augmented sixth resolves outward: le → sol, fi → sol

## Types of Augmented-Sixth Chords

### Italian Augmented Sixth (It.)

**Members:** le, do, fi (3 notes)

| Voice | Note | Doubling |
|-------|------|----------|
| Bass | le | — |
| Inner | do | Doubled |
| Upper | fi | — |

**Figured bass:** slashed 6

**Why double do?** Cannot double bass (chord of the sixth), cannot double fi (chromatic alteration).

### French Augmented Sixth (Fr.)

**Members:** le, do, re, fi (4 notes)

| Voice | Note |
|-------|------|
| Bass | le |
| Inner | do, re |
| Upper | fi |

**Figured bass:** slashed 6, 4, 3

**Character:** Contains tritone do-fi AND tritone le-re. Very dissonant.

### German Augmented Sixth (Ger.)

**Members:** le, do, me, fi (4 notes)

| Voice | Note |
|-------|------|
| Bass | le |
| Inner | do, me |
| Upper | fi |

**Figured bass:** slashed 6, 5

**Usage:** Almost always in minor; followed by cadential 6/4 (me and do carry over).

### Swiss Augmented Sixth (Sw.)

**Members:** le, do, ri, fi (4 notes)

| Voice | Note |
|-------|------|
| Bass | le |
| Inner | do, ri |
| Upper | fi |

**Figured bass:** slashed 6, slashed 4, 3

**Etymology:** Sounds German but spelled French (ri instead of me). Named for Switzerland's linguistic mixture.

**Usage:** In major keys; ri → mi, do carries over to cadential 6/4.

**Conventions:** "Swiss" is V1's name. OMT 2e (`v2/05-chromaticism/03-augmented-sixth-chords.md`) does not name a separate chord. It calls le–do–ri–fi a **Ger+6 spelled with ri**, the usual major-key spelling, because the following cad. 6/4 has mi and ri–mi shows the rising line. The sound and voice-leading are the same either way.

### German Diminished Third (Ger°3)

**Members:** fi in the **bass**, then le, do, me (19th-century variant, v2 05/03).

- Inverting le/fi turns the augmented 6th into a diminished 3rd (fi below le).
- It resolves to root-position V: fi → sol up, le → sol down.
- It differs from vii°7/V (fi–la–do–me) only in having le instead of la.

## Functional Bass Notation

All augmented-sixth chords with le in bass:

```
[S6]
It./Fr./Ger./Sw.
```

The bracket indicates chromatic alteration; the specific type is labeled below.

## Voice-Leading

### Resolution Pattern

```
Aug6 → V (or cad. 6/4 → V)

le → sol (down by half step)
fi → sol (up by half step)
    ↓
  octave on sol
```

### German Sixth to Cadential 6/4

```
Ger.       →    Cad. 6/4   →    V
le-do-me-fi  →  sol-do-mi   →   sol-ti-re
  ↓               ↓              ↓
me → mi (or me holds, then → mi)
do → (holds) → ti
```

### Approach and Context (OMT 2e)

- **Bass approach la–le–sol**: the +6 can be approached by chromatic step in the bass: a chord with la in the bass (e.g. IV6, as in the K. 465 example below) → +6 on le → V on sol.
- **Lament bass / phrygian HC**: in a lament-bass progression do–te–le–sol, replacing iv6's fa with fi on le turns iv6–V (phrygian HC) into +6–V.
- +6 chords resolve to V (with or without a seventh). The Ger+6 is normally followed by a cad. 6/4, which avoids the parallel fifths le–me → sol–re.
- They can also act as embellishing (common-tone) chords; see v2 05/04.

## Compositional Application

### When to Use

1. **Intensify pre-cadential approach** - Stronger than iv or ii°6
2. **Chromaticism without modulation** - Color before V
3. **Expressive passages** - High emotional intensity

### Choice of Type

| Type | Context | Character |
|------|---------|-----------|
| It. | Any; simplest | Clean, direct |
| Fr. | Any; double tritone | Most dissonant |
| Ger. | Minor key preferred | Rich, full |
| Sw. | Major key preferred | Smoothest voice-leading in major |

## Constraints

1. **le in bass** (standard position)
2. **Resolves to V** (directly or via cad. 6/4)
3. **Do not double fi** (chromatic alteration)
4. **German sixth goes to cad. 6/4** (le–me → sol–re would make parallel 5ths). The alternative is to resolve me or le to another chord tone; v2 05/03 calls the cad. 6/4 typical.
5. **Ger°3**: fi in the bass resolves up to sol; the upper le resolves down to sol.
