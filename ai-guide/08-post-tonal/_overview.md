# Post-Tonal Theory

## Summary

Post-tonal theory provides tools for analyzing and composing music outside the tonal system. It uses mathematical models (pitch-class sets) to describe intervallic relationships and serial techniques to organize musical material.

## Key Concepts

| Concept | Definition |
|---------|------------|
| Pitch class | The 12 chromatic pitches, regardless of octave |
| Pitch-class set | An unordered collection of pitch classes |
| Interval class | The distance between pitch classes (0-6) |
| Set class | A family of related sets (transposition/inversion) |
| Twelve-tone row | An ordered arrangement of all 12 pitch classes |

## When to Use Post-Tonal Analysis

| Musical Context | Analytical Approach |
|-----------------|-------------------|
| Functional harmony | Traditional Roman numerals |
| Extended tonality | Hybrid (RN + set theory) |
| Free atonality | Pitch-class set theory |
| Serial music | Row analysis + set theory |
