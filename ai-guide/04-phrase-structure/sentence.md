# The Sentence

## Summary

The sentence is an 8-measure thematic structure consisting of a 4-bar presentation phrase (tonic prolongation) followed by a 4-bar continuation phrase (cadential drive), ending with a single cadence.

## Structure

```
Sentence (8 bars)
├── Presentation (mm. 1-4)
│   ├── Basic Idea (mm. 1-2)
│   └── Basic Idea repeated (mm. 3-4)
└── Continuation (mm. 5-8)
    ├── Fragmentation/Development (mm. 5-6/7)
    └── Cadence (mm. 7-8)
```

## Presentation Phrase (mm. 1-4)

### Melodic Content
- **Basic Idea (BI)**: 2-bar melodic unit
- **Repetition**: BI repeated (exact or varied)
- Defined by rhythm and contour, not exact pitches

### Harmonic Content
- **Function**: Tonic prolongation
- **Typical patterns**:
  - `I - V6 - I` (neighbor)
  - `I - V4/3 - V6/5 - I` (passing)
  - `I - (ii6) - I` (subsidiary)

### Functional Bass
```
T1 - D(7)n - T1  or  T(1 - D - 1)
```

## Continuation Phrase (mm. 5-8)

### Continuation Function Characteristics

| Characteristic | Description |
|----------------|-------------|
| Fragmentation | Melodic units shrink (2→1 bar) |
| Liquidation | Characteristic → Conventional material |
| Sequence | Fragments repeated at new pitch |
| Surface acceleration | Shorter note values |
| Harmonic acceleration | Faster chord changes |

Not all characteristics need be present; typically 2-3 appear.

### Cadential Function

The continuation ends with cadential progression:

| Cadence Type | Progression | Strength |
|--------------|-------------|----------|
| PAC | S - D - T (melody on do) | Strong |
| IAC | S - D - T (melody on mi/sol) | Moderate |
| HC | ... - D | Weak |

### Typical Cadential Progressions

```
I - IV6 - Cad.6/4 - V7 - I  (PAC)
T1 - S6 - D5 - T1

I - ii6 - V - I  (PAC)
T1 - S6 - D5 - T1
```

## Compositional Application

### Building a Sentence

1. **Create Basic Idea** (2 bars)
   - Memorable melodic shape
   - Clear rhythmic profile
   - Harmonically on tonic

2. **Repeat Basic Idea** (mm. 3-4)
   - Exact repetition OR
   - Varied (different register, slight alterations)
   - Maintain harmonic stability

3. **Fragment** (mm. 5-6)
   - Take 1-bar portion of BI
   - Sequence it (up or down step/third)
   - Increase rhythmic activity

4. **Cadence** (mm. 7-8)
   - Liquidate melodic character
   - Use conventional figures (scales, arpeggios)
   - Strong cadential progression

### Variation: Extended Continuation

Continuations are often 6 bars (not 4):
- More fragmentation
- Delayed cadence
- Internal expansion

## Constraints

1. Presentation must prolong tonic (no modulation)
2. BI must be repeated (varied OK, but recognizable)
3. Single cadence at end (not multiple)
4. Continuation must show momentum increase

## Comparison with Period

| Feature | Sentence | Period |
|---------|----------|--------|
| Structure | BI + BI + Cont. | BI + CI, BI + CI |
| Cadences | 1 (end) | 2 (weak + strong) |
| Repetition | Immediate (BI+BI) | Structural (Ant.→Cons.) |
| Character | Forward momentum | Balance/symmetry |
