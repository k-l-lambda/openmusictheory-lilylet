# Phrase Structure

## Summary

Phrase structure describes how melodic and harmonic elements combine to create 8-16 measure thematic units. The two primary types are the sentence and the period.

## Primary Theme Types

| Type | Length | Structure | Cadence Pattern |
|------|--------|-----------|-----------------|
| Sentence | 8 bars | Presentation + Continuation | Single cadence |
| Period | 8 bars | Antecedent + Consequent | Weak → Strong |
| Hybrid | 8 bars | Mixed elements | Varies |
| Compound | 16 bars | Expanded versions | Multiple |

## Functional Units

| Unit | Length | Function |
|------|--------|----------|
| Basic Idea (BI) | 2 bars | Primary melodic material |
| Contrasting Idea (CI) | 2 bars | New material, leads to cadence |
| Presentation | 4 bars | BI + BI (repetition) |
| Continuation | 4 bars | Fragmentation → Cadence |
| Antecedent | 4 bars | BI + CI → Weak cadence |
| Consequent | 4 bars | BI + CI → Strong cadence |

## Harmonic Correlation

| Phrase Function | Typical Harmony |
|-----------------|-----------------|
| Presentation | Tonic prolongation |
| Continuation | Increased motion → Cadence |
| Antecedent | T prolongation → HC/IAC |
| Consequent | T prolongation → PAC |
