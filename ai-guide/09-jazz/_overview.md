# Jazz

## Summary

Traditional (swing/bebop-era) jazz harmony is written in absolute chord symbols, built on the ii–V–I schema, elaborated by inserted and substituted chords, and voiced with the root in the bass and 3rds/7ths/extensions above. The blues supplies its own forms and scale.

## Core Devices

| Device | Mechanism | File |
|------|-----------|------|
| Chord symbols | Root + quality + extensions + /bass; defaults: major triad, minor 7th, major/perfect extensions | jazz-harmony |
| ii–V–I | mi7–7–ma7 (major), ø7–7–mi7 (minor), roots by fifth | jazz-harmony |
| Embellishing chords | Insert applied V7, applied ii7 or CT°7 | jazz-harmony |
| Substitutions | Applied-dominant, mixture (le), tritone sub of V7 | jazz-harmony |
| Chord-scale theory | Roman numeral → mode | jazz-harmony |
| Voicing | Omit 5th, 3–7 core, 9/13 top line, wide-low/close-high | jazz-voicings |
| Blues | 12-bar, 16-bar, minor and jazz blues; blues scale; aab | jazz-voicings |
