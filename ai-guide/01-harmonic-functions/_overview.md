# Harmonic Functions

## Summary

Harmonic function describes the role a chord plays in creating harmonic progression. The three primary functions are Tonic (T), Subdominant (S), and Dominant (D).

## Core Framework

A theory of harmonic functions is based on three principles:

1. **Chords are collections of scale degrees**
2. **Each scale degree has characteristic tendencies**
3. **The collective tendencies determine the chord's function**

## The Three Functions

| Function | Symbol | Characteristic | Role in Phrase |
|----------|--------|----------------|----------------|
| **Tonic** | T | Stability, rest | Beginning, ending |
| **Subdominant** | S | Tension, motion away | Prepares dominant |
| **Dominant** | D | Maximum tension | Resolves to tonic |

## Roman Numeral Mapping

| Function | Primary Chords | Secondary Chords |
|----------|---------------|------------------|
| **Tonic (T)** | I, i | III, iii, VI, vi |
| **Subdominant (S)** | IV, iv, II, ii | |
| **Dominant (D)** | V, v | VII, vii° |

## Compositional Application

The fundamental harmonic cycle in tonal music:

```
T → S → D → T
```

This can be expanded:
- T alone (static)
- T → D → T (basic motion)
- T → S → D → T (full cycle)
- T → S → T (plagal motion)
